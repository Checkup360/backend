# Checkup360 Backend API

Core API for the **Checkup360** occupational health platform, built with **FastAPI**, **SQLAlchemy** (async), and **PostgreSQL**, managed by **uv**.

It coordinates unified authentication, medical user profiles, organization and membership hierarchies, health questionnaire management, and delegation to the risk scoring microservice (`engine`).

---

## Architecture

The backend strictly follows **Hexagonal Architecture (Clean Architecture / Ports & Adapters)** and tactical **Domain-Driven Design (DDD)**:

```text
Presentation ──> Application ──> Domain
Infrastructure ──> Application ──> Domain
Infrastructure ──────────────────> Domain
```

- **Domain (`app/domain`):** Entities, Value Objects, Domain Services, and Repository interfaces. Completely framework-agnostic (never imports FastAPI, Pydantic, SQLAlchemy, or HTTP).
- **Application (`app/application`):** Feature use cases, internal DTOs, and outbound port interfaces (`EmailSender`, etc.).
- **Infrastructure (`app/infrastructure`):** SQLAlchemy models and concrete repositories, authentication (FastAPI Users, OAuth, cookies), SMTP email delivery, and runtime configuration.
- **Presentation (`app/presentation`):** Thin FastAPI routers, Pydantic request/response schemas, error mappers, and dependency injection composition (`api/dependencies.py`).

Architectural constraints are documented in [`AGENTS.md`](../AGENTS.md) and [`docs/adr/0001-hexagonal-backend-structure.md`](docs/adr/0001-hexagonal-backend-structure.md).

## Prerequisites

- **Python**: `>=3.12`
- **uv** (Astral): Fast Python package and virtual environment manager.
- **PostgreSQL**: Running instance (e.g. on port `5432`).

Install `uv` if not already installed:

```bash
curl -Ls https://astral.sh/uv/install.sh | sh
```

## Getting Started

### 1. Environment & Dependencies

```bash
cd backend
uv venv
uv sync
```

### 2. Environment Variables

Copy the example environment file and adjust the values as needed (each variable and format is documented with comments inside `.env.example`):

```bash
cp .env.example .env
```

### 3. Run Database Migrations

Apply pending Alembic migrations:

```bash
make migrate
```

*(Equivalent to: `uv run alembic upgrade head`)*

### 4. Seed Superuser Account (Optional)

Create the initial platform administrator:

```bash
SUPERUSER_EMAIL=admin@checkup360.com SUPERUSER_PASSWORD=admin123 uv run python scripts/seed_superuser.py
```

---

## Running the Development Server

Start FastAPI with live reload:

```bash
make dev
```

*(Or directly: `uv run fastapi dev app/presentation/main.py`)*

The backend will be available at:
`http://localhost:8000`
- **Interactive Swagger UI:** `http://localhost:8000/docs`
- **ReDoc Documentation:** `http://localhost:8000/redoc`

## Alembic Database Migrations

The `Makefile` provides shortcuts for Alembic workflows:

```bash
# Apply migrations to latest version
make migrate

# Create a new revision autogenerated from model changes
make revision m="describe_change"

# Roll back the most recent migration
make downgrade
```

## Testing and Pre-commit

```bash
# Run unit & integration tests with coverage
make test

# Install pre-commit hooks
uv run pre-commit install

# Manually trigger pre-commit checks
uv run pre-commit run --all-files
```
